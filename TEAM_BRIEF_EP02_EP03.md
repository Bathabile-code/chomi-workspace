## EP02: Email → Expert Agent → Incident

### What We're Showing

**The Pipeline (Already Built):**
- Email arrives at mails.dev
- MCP Bridge processes the email
- ServiceNow API creates incidents/cases
- CMDB provides context (services, CIs, relationships)

**The OpenClaw Angle (What EP02 Adds):**
- OpenClaw orchestrates the pipeline
- Spawns independent expert sub-agents
- Agents reason about the operating model
- Agents validate before executing
- Agents report back

### The Narrative

**Old thinking:** "AI will accelerate bad data"

**New thinking:** "Spawn independent expert agents that understand the operating model, validate the foundation, then execute with confidence"

### Key Scenes

1. **Setup:** Email arrives (30 sec)
2. **Expert Agent:** Agent reasons + validates (2 min)
3. **Scale:** 1,000 emails processed autonomously (1 min)
4. **Foundation:** CMDB as the source of truth (1 min)
5. **Future:** Independent experts, no human architects (1 min)
