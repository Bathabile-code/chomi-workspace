# AutoSite SA Design System

Based on: https://github.com/rohitg00/awesome-claude-design

## V2 — Dark Premium Theme (Active)

Used for: Mandlolwazi Awnings (2026-05-27)

### Principles
- **Glass morphism** — Translucent cards with backdrop blur
- **Dark theme** — #0c0a09 background for premium feel
- **Warm amber accent** — #f59e0b with glow effects
- **Bold typography** — Space Grotesk for headlines
- **Single accent rule** — One accent color per surface

### Color Palette
```
--bg: #0c0a09
--bg-elevated: #1c1917
--accent: #f59e0b
--text: #fafaf9
--glass: rgba(255, 255, 255, 0.05)
--glass-border: rgba(255, 255, 255, 0.1)
```

### Typography
- **Headlines:** Space Grotesk, weight 700
- **Body:** Inter, weights 400-700
- **Scale:** 0.875rem to 5.5rem

### Components
- **Buttons:** 12px radius, accent fill, glow shadow
- **Cards:** 16px radius, glass background, hover glow
- **Nav:** Fixed, glass material, blur backdrop
- **Gallery:** Image hover with slide-up overlay

## Future Sites
All AutoSite SA generated sites should use this design system as default.
Customize accent color per client brand.
